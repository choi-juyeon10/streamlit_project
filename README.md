### 💰 금융투자성향 퀴즈 앱

Streamlit을 활용하여 구현한 투자 성향 분석 웹 애플리케이션입니다.
사용자가 퀴즈를 통해 자신의 투자 성향을 파악하고, 이에 맞는 투자 스타일을 추천받을 수 있습니다.

### 📌 주요 기능
- 🔐 로그인 기능
- ⚡ 캐싱 기능 (캐싱을 통해 반복적인 데이터 로딩을 줄이고 앱의 성능을 향상)
- 📝 금융 투자 성향 퀴즈
- 📊 결과 분석 및 투자 유형 추천

### 🧠 프로젝트 목적
투자 경험이 없는 사용자도
자신의 투자 성향을 이해하고 적절한 투자 방향을 고민해볼 수 있도록 돕기 위해 제작되었습니다.
